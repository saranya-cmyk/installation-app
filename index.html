⚡ สำคัญมาก — ถ่ายตามลำดับ ①②③ ทุกจุดค่ะ และเปิด GPS บนมือถือด้วยนะคะ
1
ถ่ายป้ายเก่า
ถ่ายป้ายโฆษณาเดิมที่ยังติดอยู่ก่อนเปลี่ยน 1-2 รูปก็พอค่ะ
รูปสินค้าเก่า
2
ถ่าย Code ที่เสา ⭐ สำคัญที่สุด
ถ่ายตัวเลขบนเสา เช่น DP800 ให้ชัดๆ ใกล้ๆ แสงพอค่ะ ถ่ายตรงๆ ไม่เอียงนะคะ ระบบจะอ่าน Code อัตโนมัติค่ะ
จุดแบ่งก่อน/หลัง
3
ถ่ายป้ายใหม่
ถ่ายป้ายใหม่ที่ติดเสร็จแล้ว ถ่ายหลายรูปได้เลยค่ะ ทั้งใกล้และไกล
รูปสินค้าใหม่
📍 วิธีเปิด GPS (ทำครั้งเดียว)
1. Settings → Location → เปิด On
2. App Permissions → Camera → อนุญาต Location
3. ถ่ายรูปทดสอบ 1 รูป — GPS จะติดมาค่ะ
